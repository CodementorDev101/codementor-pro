# CodeMentor+ Pro

A hybrid Learning Management and Coding Practice Platform built for IT students.
Live at: https://codementorpro.codes

## About

CodeMentor+ Pro is a full-stack web application developed as a capstone/thesis project
by a 4-member team (2 developers, 2 researchers). It combines a Learning Management
System with an adaptive coding practice environment, featuring automated code execution
and role-based dashboards for Students, Instructors, and Admins.

## Features

- Role-based dashboards for Students, Instructors, and Admins
- Monaco Editor (VS Code-powered) for in-browser coding
- Automated code execution via Judge0 CE API
- Supports 5 languages: Python, Java, C++, JavaScript, and C
- Automated grading and submission results
- JWT-based authentication
- Real-time compile and runtime error feedback

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React + Vite |
| Backend | Node.js + Express |
| Database | MySQL + Sequelize ORM |
| Code Execution | Judge0 CE API |
| Editor | Monaco Editor |
| Auth | JWT |
| Deployment | Railway |
